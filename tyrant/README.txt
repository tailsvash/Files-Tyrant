Files Tyrant - install steps
1. Unzip this whole folder (right-click the zip > Extract All).
2. Double-click Install-Files-Tyrant.cmd and say Yes when Windows asks for admin.
3. Open "Files Tyrant" from the Start menu.
To remove it later: Settings > Apps > Installed apps > Files Tyrant > Uninstall.
Note: if you already have an official "Files - Dev" build installed, this replaces it.
