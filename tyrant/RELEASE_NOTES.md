**Files Tyrant** is a personal mod of the [Files](https://github.com/files-community/Files) file manager. It adds a **clock in the title bar** (with settings), on top of Files' built-in custom background images.

## Install (Windows 10/11, 64-bit)
1. Download **Files-Tyrant-x64.zip** below and unzip it (right-click > Extract All).
2. Double-click **Install-Files-Tyrant.cmd** and click Yes when Windows asks for admin. (It trusts the included signing certificate, then installs the app.)
3. Open **Files Tyrant** from the Start menu.

To remove it: Settings > Apps > Installed apps > Files Tyrant > Uninstall. If you have an official "Files - Dev" build, this replaces it.

## Using the new bits
- **Clock**: Settings > Appearance > *Show clock in the title bar*. Options: 24-hour time, show seconds, show date.
- **Background image**: Settings > Appearance > Background image (or right-click an image > *Set as app background*).
